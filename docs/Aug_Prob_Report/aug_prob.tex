\section{Objective}
This report has 3 main objectives:
\begin{itemize}
	\item Summarize what copy-paste experiments are currently being executed.
	\item Quantify how each selected copy-paste configuration affects detection performance.
	\item Clearly state the current problems observed from the latest seed-123 results.
\end{itemize}

\vspace{1em}
\section{Research Summary}

\textbf{Current focus:} We are analyzing \textbf{how copy-paste augmentation configuration choices affect AP metrics}.

\vspace{0.5em}
The two completed experiments used in this report are:
\begin{itemize}
	\item \textbf{Exp 15 (MinneApple):} ratio sweep with score-guided selection and fixed \texttt{same\_image\_only=true}.
	\item \textbf{Exp 17 (Global Wheat Head):} A/B test of \texttt{same\_image\_only} on/off under random selection.
\end{itemize}

\vspace{0.5em}
\textbf{Important scope note:} This report intentionally uses \textbf{seed 123 only} as requested. Therefore, conclusions should be treated as directional and not final until multi-seed confirmation.

\vspace{1em}
\section{What Experiments I Am Doing}

\subsection{Experiment 15: Dataset Ratio Sweep (MinneApple)}
\textbf{Goal:} Check how the number of generated augmented images (\texttt{dataset\_ratio}) changes performance.

\textbf{Main controlled setup:}
\begin{itemize}
	\item Dataset: MinneApple.
	\item Selection mode: score-guided (\texttt{use\_score\_guidance=true}).
	\item \texttt{same\_image\_only=true}.
	\item Ratios tested: \{0.5, 1.0, 2.0, 3.0\}.
	\item Other copy-paste settings fixed: min/max pasted objects (2, 8), reuse caps (3, 3), overlap avoidance enabled.
\end{itemize}

\subsection{Experiment 17: Same-Image-Only Flag Check (Global Wheat Head)}
\textbf{Goal:} Decide whether \texttt{same\_image\_only} should be enabled.

\textbf{Main controlled setup:}
\begin{itemize}
	\item Dataset: Global Wheat Head.
	\item Selection mode: random (\texttt{use\_score\_guidance=false}).
	\item \texttt{dataset\_ratio=2.0} fixed.
	\item Compare two conditions only:
	\begin{itemize}
		\item \texttt{same\_image\_only=true}
		\item \texttt{same\_image\_only=false}
	\end{itemize}
\end{itemize}

\section{Current Problems Seen From These Results}

\subsection{Problem 1: Copy-paste strength (dataset ratio) is not giving net AP gains in Exp 15}
Even the best tested ratio still underperforms baseline in overall COCO\_AP. This suggests that simply increasing or decreasing generated sample count is not enough to improve generalization on MinneApple under current paste quality and placement settings.

\subsection{Problem 2: The \texttt{same\_image\_only} switch changes metric trade-offs, but does not solve the AP drop}
In Exp 17, turning \texttt{same\_image\_only} off gives slightly better overall AP, but both on/off remain below baseline. This means the flag matters, but it is not the root cause of the performance gap.

\subsection{Problem 3: Metric behavior is inconsistent across object scales}
From Exp 15 and Exp 17, some settings help one slice (for example AP\_large or AP\_small) while hurting overall AP. This indicates augmentation is changing the training distribution in a way that is not uniformly beneficial.

\vspace{1em}
\section{Practical Conclusion (Seed 123 Only)}
\begin{itemize}
	\item For Exp 15, no tested \texttt{dataset\_ratio} improves overall AP over baseline.
	\item For Exp 17, if forced to pick one option from this seed, \texttt{same\_image\_only=false} is preferable for overall AP.
	\item Current bottleneck is likely not a single scalar hyperparameter; it is likely related to paste realism, localization quality after paste, or distribution mismatch introduced by synthetic samples.
\end{itemize}
